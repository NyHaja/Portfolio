# ⚜️ Projet Web

1. Faire un CV en version portfolio en présentant les anciens projets(Sokoban, Cisco, Arbre généalogique), les hobby, etc...✅️
2. Traduction en au moins deux langues (français + Anglais) avec `PHP`✅️
3. Le site doit être resposive✅️
4. Doit avoir un formulaire qui utilisera la méthode `GET` & un formulaire qui utilisera la méthode `POST`✅️
5. Les formulaire devront avoir une vérification avant envoi avec JavaScript✅️
6. Avoir au moins un appel `AJAX` sur le site => proposition d'avoir un bouton "Voir plus de projets" sur la page d'accueil✅️
7. Gestion de base de données via des class `PHP`✅️
8. Utilisation de PDO obligatoire pour la connexion à la Base de donées✅️
9. Utiliser `SQlite` comme Base de Données✅️
10. Ajout du mode nuit🌓️
11. Une page pour ajouter un projet✅️

## ❌️ N.B
